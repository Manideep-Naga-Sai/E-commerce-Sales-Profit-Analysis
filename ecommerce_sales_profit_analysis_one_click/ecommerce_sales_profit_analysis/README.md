# E-commerce Sales & Profit Analysis

A runnable end-to-end data analyst portfolio project covering:

- Revenue
- Profit and profit margin
- Orders and units sold
- Average order value (AOV)
- Monthly growth
- Product performance
- Category performance
- Regional performance
- Customer segments
- Discount vs. profitability
- Interactive Streamlit dashboard
- SQL business analysis

## 1. Project structure

```text
ecommerce_sales_profit_analysis/
├── app.py
├── requirements.txt
├── README.md
├── data/
│   └── ecommerce_sales.csv          # generated by the data script
├── src/
│   ├── generate_data.py
│   ├── analysis.py
│   └── data_cleaning.py
├── sql/
│   └── business_analysis.sql
├── notebooks/
│   └── README.md
└── outputs/
```

## 2. Run it

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python src/generate_data.py
streamlit run app.py
```

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/generate_data.py
streamlit run app.py
```

The dashboard opens in your browser.

## 4. Replace the generated dataset

The app expects these columns:

```text
Order_ID
Order_Date
Customer_ID
Product_ID
Product_Name
Category
Sub_Category
Quantity
Unit_Price
Discount
Sales
Cost
Profit
Region
State
City
Customer_Segment
```

Replace `data/ecommerce_sales.csv` with your own file using the same column names, or modify `src/data_cleaning.py`.
