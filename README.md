# 📊 E-commerce Sales & Profit Analysis

An end-to-end **e-commerce data analytics project** built using Python, Pandas, SQL, Plotly, and Streamlit.

## 🚀 Features

* 📈 Revenue & Profit Analysis
* 💰 Profit Margin Analysis
* 🛒 Orders & Average Order Value (AOV)
* 📅 Monthly Sales & Profit Trends
* 📦 Product & Category Analysis
* 🌎 Regional Performance Analysis
* 👥 Customer Segment Analysis
* 📊 Interactive Streamlit Dashboard
* 🔍 Filters for Date, Region, Category, and Customer Segment

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* SQL
* Streamlit
* Plotly
* DuckDB

## ▶️ How to Run

### Windows

Double-click:

```text
run_project.bat
```

### Mac/Linux

Run:

```bash
chmod +x run_project.sh
./run_project.sh
```

The project will automatically set up the environment, install dependencies, and launch the Streamlit dashboard.

## 📊 Dashboard

* Product & Category Analysis

* Customer Analysis

## 📂 Dataset

The project includes a sample e-commerce dataset.

You can also replace the CSV file in:

```text
data/ecommerce_sales.csv
```

with your own compatible e-commerce data.

## 🎯 Project Goal

The goal of this project is to analyze e-commerce sales data and identify trends in **revenue, profitability, products, regions, and customers** using data analytics and visualization.
